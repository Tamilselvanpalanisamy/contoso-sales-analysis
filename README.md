📊 Contoso Sales Analysis Report
📌 Project Overview

This project focuses on analyzing Contoso sales data using an interactive Power BI report.
The report provides insights into sales performance, profitability, product trends, and geographical sales distribution to support business decision-making.

The project helps stakeholders monitor KPIs, identify top-performing regions and brands, and analyze profit trends over time.

🎯 Problem Statement

Businesses need a centralized reporting solution to:

Monitor overall sales and profit performance
Analyze regional and store-level sales trends
Track product brand profitability
Identify sales growth patterns
Enable interactive business analysis through filters and drilldowns

This report addresses these challenges using dynamic Power BI visualizations.
